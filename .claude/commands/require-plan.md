## 用户输入

```text
$ARGUMENTS
```

## 执行目标

调用架构专家进行需求分析，输出完整解决方案后**等待用户确认**，确认后才安排专家执行开发。

## 执行步骤

### 步骤 1: 调用架构专家分析需求

请调用 architecture-planning-expert agent，深度理解以下需求：

需求内容：$ARGUMENTS

架构专家需要：

1. 深度分析需求的业务目标和技术可行性
2. 识别涉及的功能模块和技术栈
3. 拆解任务并确定优先级
4. 规划完整解决方案
5. ⚠️ **仅输出方案，暂不安排专家执行**

### 步骤 2: 输出方案并等待确认

分析完成后，输出完整解决方案，并在末尾添加：

```
⚠️ 请确认上述方案，确认后我将安排专家执行
```

**然后暂停，等待用户确认。**

### 步骤 3: 用户确认后执行

当用户回复"确认"、"可以"、"执行"等确认关键词后，按照 `/require` 命令流程安排专家执行开发。

## 与 /require 的区别

| 命令            | 确认机制     | 流程                   |
| --------------- | ------------ | ---------------------- |
| `/require`      | 无确认       | 分析后直接执行         |
| `/require-plan` | **强制确认** | 输出方案 → 确认 → 执行 |

## 使用示例

```bash
/require-plan 我需要增加一个用户评论功能

# AI输出方案 → 等待确认
# 用户回复"确认"
# AI开始安排专家执行
```
