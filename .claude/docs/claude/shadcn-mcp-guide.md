# shadcn/ui MCP 集成使用指南

## 📋 概述

本项目已集成 shadcn/ui MCP (Model Context Protocol) 服务器，为 AI 辅助开发提供智能化的组件管理和生成能力。

## 🔧 配置状态

- ✅ MCP 服务器已配置 (`.mcp.json`)
- ✅ shadcn CLI 已安装 (`shadcn@^3.6.1`)
- ✅ 13个 shadcn/ui 组件已集成
- ✅ frontend-expert agent 已增强 MCP 工具使用指导
- ✅ Claude Code 权限已配置

## 🔍 AI 提示技巧

### 1. 明确指定使用 MCP 工具

```

"请使用 shadcn/ui MCP 工具分析现有的组件配置"

❌ 不推荐：
"分析现有的组件配置"
```

### 2. 提供具体的技术要求

```
✅ 正确：
"使用 MCP 工具创建一个带有以下特性的对话框组件：
- 尺寸：sm, md, lg 三种尺寸
- 变体：default, destructive, outline
- 支持自定义标题和内容
- 包含确认和取消按钮"

"创建一个对话框组件"

```
✅ 正确：

- input (文本输入)
- button (操作按钮)

- 自动处理所有依赖关系"

❌ 不推荐：

## 🎯 开发流程建议

### Phase 1: 需求分析

1. 明确功能需求和用户场景
2. 确定所需的 shadcn/ui 组件
3. 评估与现有组件的集成方式

### Phase 2: AI 辅助开发

1. 使用具体的提示请求 MCP 工具
2. 让 AI 分析现有组件状态
3. 基于项目设计系统生成组件

### Phase 3: 集成和优化

1. 将生成的组件集成到项目
2. 测试组件功能和交互
3. 优化性能和无障碍性

## 🛠 故障排除

### 如果 MCP 工具无法识别：

1. 检查 `.mcp.json` 配置是否正确
2. 确认 `shadcn@latest` 包已安装
3. 重启 Claude Code 以加载新的配置

### 如果组件生成不正确：

1. 提供更详细的技术规范
2. 明确指定设计系统要求
3. 检查现有组件的配置和依赖
