## 二、技术架构

### 2.1 技术栈概览

```
┌─────────────────────────────────────────────────────────────┐
│ 前端层 (Frontend)                                            │
├─────────────────────────────────────────────────────────────┤
│ Next.js + React + TypeScript + shadcn/ui + Tailwind CSS    │
│ 状态管理: Zustand | HTTP客户端: Axios                        │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ API层 (API Routes)                                           │
├─────────────────────────────────────────────────────────────┤
│ Next.js API Routes + Zod Schema验证 + JWT认证              │
│ 路由前缀: /api/*                                             │
└─────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
┌───────────────────┐ ┌───────────────┐ ┌───────────────────┐
│ 数据层 (Data)     │ │ 存储层 (IO)   │ │ 消息层 (Async)    │
├───────────────────┤ ├───────────────┤ ├───────────────────┤
│ Prisma ORM        │ │ MinIO         │ │ Kafka             │
│ MongoDB           │ │ 文件存储      │ │ 异步任务队列      │
│ 数据持久化        │ │ 大文件存储    │ │ 结果通知          │
└───────────────────┘ └───────────────┘ └───────────────────┘
```

### 2.2 核心技术栈

| 组件     | 技术选型             | 用途                     |
| -------- | -------------------- | ------------------------ |
| 前端框架 | Next.js (App Router) | 服务端渲染、API路由      |
| UI组件库 | React + shadcn/ui    | 组件化开发、主题化设计   |
| 样式方案 | Tailwind CSS         | 原子化CSS                |
| 类型系统 | TypeScript           | 类型安全                 |
| 状态管理 | Zustand              | 轻量级全局状态           |
| 数据验证 | Zod Schema           | 前后端双重验证           |
| ORM      | Prisma               | 数据库数据访问           |
| 文件存储 | MinIO                | 大文件分片上传、文件管理 |
| 消息队列 | Kafka                | 异步任务调度、结果通知   |
| 认证     | JWT Token            | 用户身份验证             |
