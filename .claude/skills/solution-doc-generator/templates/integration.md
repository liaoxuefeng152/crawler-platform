## 七、任务状态设计

### 7.1 主实体状态

| 状态值     | 中文名称 | 说明     |
| ---------- | -------- | -------- |
| pending    | 待处理   | 状态说明 |
| processing | 处理中   | 状态说明 |
| completed  | 已完成   | 状态说明 |
| failed     | 失败     | 状态说明 |

### 7.2 子状态

当主实体状态为 processing 时的子状态：

| 状态值 | 中文名称 | 说明     |
| ------ | -------- | -------- |
| SUB_A  | 子状态A  | 状态说明 |
| SUB_B  | 子状态B  | 状态说明 |

### 7.3 状态流转

```
pending → processing → completed
              ↓
            failed
```

### 7.4 进度追踪

通过 REST API 返回的 progress 字段实时追踪处理进度：

| progress值 | 含义               |
| ---------- | ------------------ |
| 0-99       | 处理中，百分比进度 |
| 100        | 处理完成           |
| -1         | 处理失败           |
