**📋 文档概述**

本文档定义了个贷处置平台与个贷字段提取系统之间的接口交互规范，核心内容：

1\. **借款人列表管理**：下载模板 → 填写上传 → 补充人员

2\. **资产包上传**：上传压缩包到 MinIO source 目录

3\. **AI任务调度**：通过 Kafka 消息队列异步处理

4\. **结果获取**：定时查询进度 + 消费结果队列

\> 💡 **相关文档**：\[个贷处置平台架构文档\]([./个贷处置平台架构文档.md]{.underline}) - 包含数据库模型、状态管理等详细设计

**1.2 目录职责**

---

目录 创建方 说明

source/ 个贷处置平台 存放资产包压缩包（archive.zip）

personList/ 个贷字段提取系统 人员分类后的文件，包含关联文件和高亮文档

personList/{姓名}/highlighted/ 个贷字段提取系统 字段高亮标注后的PDF文档

---

**1.3 路径规则**

\- **资产包目录**：以资产包编号命名，如 \`PKG001\`

\- **压缩包路径**：\`asset-packages/{packageNo}/source/archive.zip\`

\- **人员文件路径**：\`asset-packages/{packageNo}/personList/{姓名}/{文件名}\`

\- **高亮文件路径**：\`asset-packages/{packageNo}/personList/{姓名}/highlighted/{字段名}\_highlighted.pdf\`

**二、双方职责**

**2.1 王振科（个贷处置平台 Next.js）**

---

职责 说明

借款人列表管理 Excel模板下载、上传、添加人员

上传压缩包 同步上传资产包压缩包到 MinIO source/ 目录

创建队列 创建 wangzhenke_loan-task Topic

生产任务消息 上传完成后，发送任务消息（包含源文件位置和存储位置）

消费结果消息 消费 houxin_task-result Topic 获取结果

查询任务进度 定时调用个贷字段提取系统 REST API 查询进度

数据落库 解析结果消息，借款人信息和字段结果存入 MongoDB

**2.2 侯鑫（个贷字段提取系统 Python）**

---

职责 说明

消费任务消息 消费 wangzhenke_loan-task Topic 获取任务

解压文件 从 source/ 读取压缩包并解压

创建队列 创建 houxin_task-result Topic

提供REST API 提供任务状态查询、子任务重试等接口

执行分析 OCR识别、字段提取、人员分类

**七、任务状态设计**

**7.1 资产包状态（AssetPackage.status）**

---

状态值 中文名称 说明

pending 待上传 借款人列表已确认，等待上传压缩包

uploading 上传中 用户正在上传压缩包

analyzing 分析中 个贷字段提取系统正在处理

completed 已完成 全部处理完成

failed 失败 处理过程中出错

---

**7.2 AI任务状态（AssetPackage.aiTaskStatus）**

当资产包状态为 analyzing 时的子状态：

---

状态值 中文名称 说明

PENDING 待处理 任务已创建，等待处理

PROCESSING 正在处理 正在执行分析

COMPLETED 处理完成 分析成功完成

FAILED 处理失败 分析过程中出错

---

**7.3 状态流转**

---

Plain Text\
 pending → uploading → analyzing → completed\
 ↓\
 failed

---

**7.4 进度追踪**

通过 REST API 返回的 progress 字段实时追踪处理进度：

---

progress值 含义

0-99 处理中，百分比进度

100 处理完成

-1 处理失败
