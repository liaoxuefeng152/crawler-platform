**一、系统定位**

**1.1 业务定位**

个贷处置平台是面向个贷业务管理的前端系统，核心功能包括：

\- **资产包管理**：上传、存储、查看资产包

\- **借款人管理**：查看、筛选、管理借款人信息

\- **主体规则配置**：动态配置需要识别的字段

\- **AI分析对接**：与个贷字段提取系统交互，获取字段提取结果

\- **溯源详情**：查看借款人溯源文件和AI提取的字段信息

**1.2 系统角色**

系统涉及以下三个角色：

---

角色 说明

个贷处置平台 Next.js 前端系统，用户交互界面，数据存储，任务调度

个贷字段提取系统 Python AI服务，OCR识别，字段提取，人员分类

用户 业务操作人员，分为管理员和普通用户。管理员可配置主体规则、管理用户；普通用户可上传资产包、查看借款人、查看溯源文件

**功能说明**：用户创建资产包、上传借款人列表、上传资产包压缩包，系统自动通知个贷字段提取系统进行解析并展示解析结果。

**时序图**：

---

sequenceDiagram\
 autonumber\
 participant User as 用户\
 participant Platform as 个贷处置平台\
 participant DB as MongoDB\
 participant MinIO as MinIO存储\
 participant AI as 个贷字段提取系统(侯鑫)\
 \
 Note over User,AI: Step 1: 创建资产包基本信息\
 \
 User-\>\>Platform: 填写基本信息（资产包名称、涉及金额）\
 Platform-\>\>DB: POST /api/asset-packages\<br/\>创建资产包记录\
 DB\--\>\>Platform: 返回 packageId\
 Platform\--\>\>User: 创建成功，返回 packageId\
 \
 Note over User,AI: Step 2: 上传借款人列表\
 \
 User-\>\>Platform: 下载 Excel 模板\
 Platform-\>\>MinIO: GET /templates/debtor-template.xlsx\
 MinIO\--\>\>Platform: 返回模板文件\
 Platform\--\>\>User: 下载 Excel 模板\
 \
 User-\>\>Platform: 上传填写好的 Excel 文件\
 Platform-\>\>Platform: 解析 Excel 内容\
 Platform-\>\>DB: POST /api/asset-packages/{id}/debtors\<br/\>保存借款人列表\
 DB\--\>\>Platform: 保存成功\
 Platform\--\>\>User: 返回借款人列表预览\
 \
 Note over User,AI: Step 3: 上传资产包压缩包\
 \
 User-\>\>Platform: 选择压缩包并确认上传\
 Platform-\>\>Platform: POST /api/asset-packages/multipart/init\<br/\>初始化分片上传\
 Platform-\>\>MinIO: 调用 MinIO 创建 multipart upload\<br/\>Bucket: user-npl-liquo\<br/\>路径: asset-packages/{packageNo}/archive/\
 MinIO\--\>\>Platform: 返回 uploadId + 预签名URL列表\
 Platform\--\>\>User: 返回预签名URL列表\
 User-\>\>MinIO: 分片直传到 MinIO（使用预签名URL）\<br/\>Bucket: user-npl-liquo\
 MinIO\--\>\>User: 返回各分片 ETag\
 User-\>\>Platform: POST /api/asset-packages/multipart/complete\<br/\>通知合并分片\
 Platform-\>\>MinIO: 调用 MinIO completeMultipartUpload\<br/\>MinIO 执行分片合并\
 MinIO\--\>\>Platform: 合并成功，文件路径确定\
 Platform-\>\>DB: 更新状态为\"分析中\"\
 Platform\--\>\>User: 上传成功，状态变更为\"分析中\"\
 \
 Note over User,AI: Step 4: 异步通知个贷字段提取系统\
 \
 Platform-\>\>AI: Kafka: wangzhenke_loan-task（发送任务）\
 AI\--\>\>Platform: Kafka: houxin_task-result（解析中）\
 \
 Note over User,AI: Step 5: 轮询查询解析结果\
 \
 loop 每10秒轮询\
 User-\>\>Platform: 查询解析进度\
 Platform-\>\>AI: GET /api/v1/tasks/{package_no}\
 AI\--\>\>Platform: 返回进度\
 Platform\--\>\>User: 显示进度条\
 end\
 \
 Note over User,AI: Step 6: 消费解析结果\
 \
 Platform-\>\>Platform: Kafka: houxin_task-result（消费结果消息）\
 Platform-\>\>DB: 同步借款人列表和提取字段信息\
 DB\--\>\>Platform: 同步成功\
 Platform-\>\>DB: 更新状态为\"已完成\"\
 Platform\--\>\>User: 状态变更为\"已完成\"\
 User-\>\>Platform: 查看资产包详情\
 Platform-\>\>DB: GET /api/asset-packages/{id}\
 DB\--\>\>Platform: 返回资产包详情\
 Platform\--\>\>User: 展示借款人列表和提取字段

**3.3.3 用户故事七：我要分配资产包权限**

**功能说明**：管理员在资产包管理页面通过操作列的\"权限分配\"按钮，将资产包的管理权限分配给其他用户。创建资产包时默认只分配给创建者本人。

**权限说明**：

---

权限类型 说明

管理权限 可查看、编辑、操作资产包及其关联的借款人数据

**四、资产包状态流转**

**4.1 资产包状态（个贷处置平台）**

资产包状态定义如下：

---

状态值 中文名称 说明 触发条件

uploading 上传中 用户正在上传压缩包 初始化分片上传时

analyzing 分析中 个贷字段提取系统正在处理 分片上传完成并发送Kafka消息后

completed 已完成 全部处理完成 收到成功结果消息

failed 失败 处理过程中出错 收到失败结果消息或处理异常

---

**4.2 AI任务状态（个贷字段提取系统）**

当资产包状态为 analyzing 时的子状态：

---

状态值 中文名称 说明

PENDING 待处理 任务已创建，等待处理

PROCESSING 正在处理 正在执行分析

COMPLETED 处理完成 分析成功完成

FAILED 处理失败 分析过程中出错

---

\> 💡 **详细说明**：AI任务状态的详细定义和进度追踪，详情参考侯鑫的《个贷字段提取系统》文档。
